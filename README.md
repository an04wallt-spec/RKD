# RKD Project

Программа расчёта стоимости РКД и формирования коммерческого предложения.

## Стабильная база

**Версия 1.3.0** — проверенная рабочая версия, дата исходной сборки: **14.08.2026**.

Эта версия зафиксирована как стабильный baseline. Дальнейшие изменения должны выполняться поверх неё отдельными коммитами/ветками. Перед слиянием изменений необходимо проверять, что уже работающая функциональность не нарушена.

## Структура

- `src/` — исходный код программы и ресурсы.
- `release/windows/` — проверенная готовая Windows-сборка версии 1.3.0.
- `docs/CHANGELOG-v1.3.txt` — исходное описание версии из поставленного архива.

## Версия 1.3

- Коммерческое предложение формируется без обязательного эскиза.
- При отсутствии изображений раздел «Эскизы изделия» не выводится.
- Блок стоимости автоматически поднимается выше.
- Сохранена работа с одним, двумя или тремя эскизами.
- Изменение действует и в обычном расчёте, и в карточке изделия проекта.

Сохранены параметры PDF: строгий A4, 300 DPI, 2480×3508, сжатие без потерь.

## Сборка

Для сборки используется `src/build.ps1` и штатный компилятор .NET Framework (`csc.exe`). Результат сборки создаётся в каталоге `build/`.

> Важно: стабильную точку версии 1.3 не переписывать. Новую функциональность добавлять отдельными коммитами с возможностью возврата к этой базе.
